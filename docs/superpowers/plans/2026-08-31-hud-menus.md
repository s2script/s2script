# HUD menus + Tab-to-activate — implementation plan

> **For agentic workers:** GitHub `gh stack` (extension `github/gh-stack`). Bottom of this stack is `cursor/cs2-custom-hud-layout` (PR #148). This docs layer is `cursor/hud-menus`. Implementation layers are added with `gh stack add <branch>` from the current top, then `gh stack submit --auto`.

**Goal:** CS2 menus (WASD HTML + chat numbers) paint `hudkit` sheets. User-requested menus activate immediately. Unsolicited ballots (votes) wait for Tab instead of the scoreboard.

**Architecture:** Keep `Menu` as the plugin API. CS2 replaces both Center and Chat renderers with one hudkit-backed renderer. `Menu.activation` is `"immediate" | "tab"`. Tab is `HudInput` + `UserCmd` `IN_SCORE` clear. Votes register a CS2 ballot presenter that displays a tab-Menu per eligible slot.

**Tech stack:** `core/js/prelude.js` + `packages/sdk/menu.d.ts` / `votes.d.ts`; `games/cs2/js/pawn.js` + `components.js` (+ new `hudinput.js` if the renderer file would get too large); `packages/cs2/ui.d.ts` or `index.d.ts` for `HudInput`; node `--test` in `games/cs2/js` and `packages/sdk`.

**Spec:** `docs/superpowers/specs/2026-08-31-hud-menus-design.md`
