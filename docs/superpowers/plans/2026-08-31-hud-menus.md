# HUD menus + Tab-to-activate — implementation plan

> **For agentic workers:** GitHub `gh stack` (extension `github/gh-stack`). Bottom of this stack is `cursor/cs2-custom-hud-layout` (PR #148). This docs layer is `cursor/hud-menus`. Implementation layers are added with `gh stack add <branch>` from the current top, then `gh stack submit --auto`.

**Goal:** CS2 menus (WASD HTML + chat numbers) paint `hudkit` **center** sheets. Unsolicited votes paint a **right-side rail**: Tab to pick **until they vote or the vote expires**; after a pick the rail stays up as a live tally until expiry.

**Architecture:** Keep `Menu` as the plugin API for lists the player asked for. CS2 replaces both Center and Chat menu renderers with one hudkit-backed **center** renderer (`activation: "immediate"`). Votes are **not** a Menu: a CS2 rail presenter on `Vote.registerTallyRenderer` docks `s2_vote` on the right. `HudInput` swallows Tab only while that slot is waiting (until pick **or** expiry). After cast: disarm, show counts, keep panel until `clear`. `VoteTally.choice` tells the presenter which state.

**Tech stack:** `core/js/prelude.js` + `packages/sdk/menu.d.ts` / `votes.d.ts`; `games/cs2/js/pawn.js` + `components.js` (+ `hudinput.js` / `voterail.js`); workshop `s2_vote*` XML/CSS; `packages/cs2` for `HudInput`; node `--test` in `games/cs2/js` and `packages/sdk`.

**Spec:** `docs/superpowers/specs/2026-08-31-hud-menus-design.md`

## Global constraints

- Origin is `github.com/s2script/s2script`.
- Do not rewrite plugins onto `hudkit.modal()`. Votes are a rail presenter, not `hudkit.modal()`.
- Vote rail **does** add XML/CSS to `s2script_lib.xml` (right dock). Do not add a third center modal.
- Do not remove `Menu` / `MenuStyle` / `freezePlayer`.
- `HudInput` / IN_SCORE / cursor are CS2. `Menu.activation` is generic. `VoteTally.choice` is generic.
- Concat order in `scripts/package-addon.sh` stays `… pawn.js ui.js components.js` (+ new file after components if added).
- Disabled Menu items must not call `onSelect` (nominations cooldown).
- Swallow Tab only while armed **and not yet active**. Vote waiting ends on **pick or expiry** — `clear` must disarm even if that slot never voted. After a pick, disarm even though the rail stays visible until expiry.
- Changesets: `@s2script/sdk` minor (activation on Menu + `VoteTally.choice`); `@s2script/cs2` minor (HudInput + renderer + rail).
- TopMenu `sheets` default `["admin"]`. Do not put existing admin items on `!menu` unless a plugin opts in.
- `!menu` is `sm_menu`. Rename cookbook `sm_menu` → `sm_menudemo` in the hub PR.
