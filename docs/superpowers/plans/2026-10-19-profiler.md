# `sm prof` — plan

Spec: [`specs/2026-10-19-profiler-design.md`](../specs/2026-10-19-profiler-design.md).
One branch, one PR: `core/profiler`.

1. **Recorder** — `core/src/profiler/mod.rs`: `Span` guard, interned owners/names, self time, frame
   windows, worst-frame lists, timeline cap, session start/stop/deferral, `sm prof status|dump|clear`.
2. **Report** — `core/src/profiler/report.rs`: summary, console report with the verdict, Chrome
   trace writer, off-thread file writing, UTC stamps.
3. **JS sampling** — `core/src/profiler/js.rs`: inspector session, `Profiler.*` calls, profile
   extraction, hot-function table. Plugin bundles compiled as `s2s://<id>/plugin.js`.
4. **V8 hooks** — `v8host.rs`: GC prologue/epilogue, promise hook (nullable `SetPromiseHook`),
   `profiler_hooks(on)`, `refresh_detour` keeps frames while profiling, `PROFILER` singleton
   dropped before the isolate.
5. **Instrumentation** — `ffi.rs` (every dispatch/replay entry + the frame phases), `dispatch.rs`,
   `sdkhooks.rs`, frame handlers, timers, interfaces, TopMenu, Engine.function hooks, lifecycle,
   microtask checkpoint.
6. **Command** — `sm prof start [seconds] [js] | stop | status | dump [rows] | clear` in
   `sm_command.rs`; players get the banner.
7. **Tests** — recorder unit tests (self time, inert guards, hook unwinding, frames + verdict,
   timeline cap, trace JSON, dates, hot functions) and in-isolate tests (plugin attribution through
   real dispatch, async continuations, GC, deferral while V8 is busy, timed stop, inspector
   sampling naming plugin functions, shutdown mid-session).
8. **Docs** — `docs/PROFILING.md`, INSTALL pointer, PROGRESS entry, changeset.

Acceptance: `make ci` green. Live: on the CS2 dev server, `sm prof start 30 js` → report printed,
three files written and openable in Perfetto / DevTools.
