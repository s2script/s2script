# First-party SDKHooks — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the fake `OnTakeDamage` public with SourceMod-shaped `SDKHook` / `SDKUnhook` for `OnTakeDamage`, per-entity, ledgered, destroy-unhooked.

**Architecture:** New `core/src/sdkhooks.rs` owns the table, natives, damage fan-out, and teardown. Prelude exposes `SDKHook` / `SDKUnhook` / `SDKHookType`. `dispatch_damage` fans only callbacks whose hooked host-id matches the victim. Existing `DispatchTraceAttack` detour stays.

**Tech Stack:** V8 natives, `entity_live` books, prelude.js, `@s2script/sdk` types, isolate tests via `v8host::frame_tests`.

### Task 2: Host table + natives + dispatch (TDD in `core/src/sdkhooks.rs`)

**Files:**
- Create: `core/src/sdkhooks.rs`
- Modify: `core/src/lib.rs`, `core/src/v8host.rs` (install_natives + drop DAMAGE_MUX dispatch/subscribe/store), `core/src/ffi.rs`, `core/src/entity_live.rs`

**Natives:** `__s2_sdkhook(index, id, type, callback) -> bool`, `__s2_sdkunhook(index, id, type, callback) -> bool`.

**Table:** `Vec<Entry { owner, generation, entity_id, kind, handler, sub_id }>`. Snapshot for victim host-id → `Vec<(owner, generation, handler)>` in subscribe order. `owner_stores` register `SDKHOOKS` (remove_by_owner / remove_by_ids / reset). `remove_by_ids` is real (sub_ids assigned even though JS returns bool).

**Victim resolve:** `damage_victim` packed handle → `decode_handle` → `entity_live::adopt` → host id. None → empty snapshot.

**Delete / map:** `on_deleted` returns evicted host id; ffi calls `sdkhooks::drop_entity`. Map-start `clear_for_map_transition` plus `sdkhooks::drop_all`.

**Throw:** unsupported type is JS-side (`Error` with named reason). Native returns false on stale/null identity.
