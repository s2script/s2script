**GameHud target label (2026-11-21). Unit-tested, not live-tested.** Gamemodes want "who you are looking at" under the crosshair (TTT names and roles, JB guard/prisoner tags). `s2script_gamehud.xml` gains `gk_target`, a compact panel centred about 60px under the crosshair with a name line (`gk_target_n`) and a small sub line (`gk_target_s`), collapsed under the scoreboard and buy menu like the other passive pieces. `GameHud.target()` claims it like the rail and status card (`gamekit:target`, one owner, freed on unload) and returns `set(audience, { name, sub?, tone? })`, `hide(audience)`, `release()`, `isValid()`. Each player's last paint is kept in the kit, so a plugin calling `set` every tick with the same content sends nothing. Fading uses `gk-fade` with a 0.1 s opacity transition: a show from collapsed un-collapses while faded and drops the fade 20 ms later so the fade-in plays; a hide fades first and collapses 200 ms later only if nothing re-showed it, so an aim crossing a gap between two players dips instead of blinking. The cookbook gains `sm_gk_target [off]` (aim trace every 4th frame, the hit player's name in team colour and their health). The workshop addon must be republished for the new ids. Live check: `docs/GAMEHUD.md` step 13.
