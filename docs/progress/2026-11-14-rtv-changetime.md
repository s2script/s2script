**RTV changes the map right away, with `rtv_changetime` (2026-11-14) — offline; live check pending.** A won RTV vote used to wait for the next round start (or match end) before changing the map, so a server that wanted a new map had to play the round out first. The winner is now applied a few seconds after the result is announced, by default. The new `rtv_changetime` config key picks when: `0` = right away (default), `1` = at the next round start or match end (the old behaviour), `2` = at the end of the map, in place of the normal nextmap rotation. The mode is fixed when the vote wins, each mode has its own winner line, and a change is dropped if another map became live first. Live check: `sm_forcertv`, vote a map, and the server changes about 3 s after the winner line; with `rtv_changetime 1` it waits for the next round; with `2` it plays out the map.
