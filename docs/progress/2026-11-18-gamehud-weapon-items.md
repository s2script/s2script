**GameHud weapon card: item marks and icons (2026-11-18). Unit-tested, not live-tested.** The first weapon card joined every item of a slot into one label and highlighted the whole row, so it could not show whether the knife or the Zeus was out, or which grenade. Each `gk_wpn_sN` row now holds four item cells (`gk_wpn_sN_i0..i3`, an Image and a Label each) and a `+N` label; the row keeps `gk-sel` for the active slot and the item in hand takes `gk-on` (full strength, the rest at 45%). `auto` marks the item by comparing the weapon entity with m_hActiveWeapon, never the name, orders a row knife before Zeus and grenades in buy order, and keeps the item in hand visible when a row collapses. Items draw the game client's own equipment icons (`file://{images}/icons/equipment/<name>.svg`, a table by item definition index in `gamekit-weapon.js`), sized by `textureheight` with `texturewidth="-1"` so no CSS scaling is needed; text joins the icon for a renamed item, an item with no icon, and a grenade count. The header shows the active weapon's icon. `set()` rows accept a string as before or `{ items, active }`, and items accept `{ text, icon }`; `options.icon` overrides an icon in auto. The slot ids changed, so the addon and runtime must ship together. Live check: `docs/GAMEHUD.md` step 10, including that every stock icon name resolves.
