**Shared native templates (2026-11-18). Unit-tested, not live-tested.** Every plugin context installed its ~400 natives with `v8::Function::new`, which builds a new function template, shared function info and `prototype` object for each one, in each context: 222 KB of every plugin's heap, more than the std prelude itself. `set_native` and `set_fast_native` (core/src/v8host.rs) now build one `FunctionTemplate` per native per isolate (keyed by name and callback type, dropped before the isolate) and instantiate it in each context, without a `prototype`, so natives are not constructors. Each plugin still gets its own function objects. Measured in the core harness with the full CS2 package: 856 KB and 4.2 ms per plugin before, 674 KB and 3.4 ms after. The full-collection pause follows heap size, so this shortens it in proportion. Live check: plugins load and run as before; `sm frames` full-GC times are no worse than on the previous build.
