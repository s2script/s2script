**GameHud sheet clean repaint (2026-11-21). Unit-tested, not live-tested.** A sheet opened after another one on the same player could show the old body's rows under or over the new one (seen with the rules plugin's list sheet followed by the TTT grid shop). Every plugin drives the same layout entity but keeps its own ui.js diff cache, so a plugin that had hidden the list body before still believed it was hidden after another plugin showed it, and dropped the write. `games/cs2/js/gamekit-sheet.js` now drops its context's cache for the sheet's panels for that player on every fresh claim (new `kit.forget`, backed by a per-slot `invalidatePanelTree(root, slot)` in `ui.js`), so the first paint sends every value. Each paint also hides the rows of the body kinds not in use and empties the rows it had shown there; past-the-page rows are emptied too, and the first paint after a claim clears every tone class on table action labels. Close empties the whole panel (bodies, rows, side tabs, heading, kicker, pager, texts) before freeing the claim, except on disconnect or map change. Panorama layout is unchanged, so the workshop addon needs no republish; the runtime needs a `v*` tag. Live check: open the rules sheet, close it, open the TTT shop on the same player; only the shop cards show.
