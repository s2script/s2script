**CS2 build 26879581 (2026-11-24). Not live-tested.** Valve's Nov 23 build (depot 2347773 manifest 4380993310429599899) inserts one virtual into `ISource2Server` at slot 14, right after `GameCreateNetworkStringTables`, on both platforms: `CSource2Server` goes 104 -> 105 slots on linuxsteamrt64 and 103 -> 104 on win64, and every later slot moves up by one. The only one s2script uses is `GameFrame` (19 -> 20 on both). With the old pins the shim refused to hook it ("slot unverified"), so on this build the frame multiplexer, timers and every per-frame dispatch were off until the gamedata update. Fix: `ISource2Server_vtableSize` 105 / 104 and `ISource2Server_GameFrame` 20 / 20 in `gamedata/core/game.cs2.jsonc`, plus `third_party/hl2sdk` on s2sdk 78c3e8c (`ISource2Server::unk_001`, so `gdgen sdk` puts `GameFrame` at [20] like the binary). Everything else is unchanged: 79 signatures, the other 15 pins and 37 tracked indices, 14 other s2sdk headers, and the schema catalog. The win64 values come from server.dll's MSVC RTTI vtable (slot 14 is the same one-line forward as on Linux, slot 20 the `GameFrame` prologue); no win64 build of the old version was compared. Live check: boot, `sm prof start 5`, confirm a timer plugin (`delay`) fires.
