**GameHud sheet and prompt (2026-11-16). Unit-tested, not live-tested.** Fifth slice of the gamemode HUD work. `games/cs2/js/gamekit-sheet.js` shares the panels layout handle with `gamekit-panels.js`, which now routes every panels button through one table and exposes a small internal kit (routes, chat handlers, slot and map hooks). `GameHud.sheet(player, spec)` is per player (`gamekit:sheet:<slot>`), takes the cursor and has a Close button. Sections sit in 16 side slots; consecutive sections with the same `group` get a header, other groups collapse when the tabs do not fit, and past that the column scrolls with up and down slots. Bodies page themselves: list (6 per page by default, numbers are the item's own `n` or its place in the whole section, so `section` + `highlight` opens a sheet on rule 3, highlighted), text (4 paragraphs), toggles (8), grid (9) and table (8 rows, 6 columns, 2 row buttons). `GameHud.prompt(player, spec)` asks one question with up to 4 answers, takes the cursor, has a Close button (`gk_pr_close`, new in the layout, so the workshop addon needs republishing) and an optional timer, and reports `{index, id, reason}`. A refused prompt goes to chat and only then accepts a typed number from that player. Live check: open a sheet with 14 rules on rule 9, page through it, then send a prompt and answer it by click.
