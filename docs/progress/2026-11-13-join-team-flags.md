**joinTeam flags (2026-11-13) — offline; live acceptance pending.** Prompted by a server log full of `[s2script] function target 9: noncanonical u8 closure argument`. Target 9 is the trusted `joinTeam` binding (`CCSPlayerController::HandleCommandJoinTeam`), which declared its third argument as a `u8` bool `queue`. It is a bit field: on build 26598758 the body tests bit 0 and bit 1 of it separately, and of its eleven direct callers in libserver nine pass 0, one passes 2 and one passes 3. The engine-function ABI refuses any `u8` above 1, so the hook logged and stood aside for those calls, and the requests went through without reaching any `Teams.onJoinTeam` handler. The binding now declares `flags: i32`; the adapter derives `view.queue` from bit 0 (what the old declaration meant) and adds `view.flags` with the raw value. The adapter contract `cs2.join-team.v1` frame reads `flags:i32` instead of `queue:bool` (its hash changes with it; the contract has no consumer outside the CS2 game package). Live check: `jointeam 2` / the team menu with an `onJoinTeam` subscriber logs no `noncanonical` line and the handler fires.
